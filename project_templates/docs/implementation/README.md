# docs/implementation

This folder contains the phase-based implementation plan for the repo.

- Canonical plan: `docs/implementation/PLAN.md`
- Worklogs live in: `docs/worklogs/`

Rule of thumb:
- Keep phases small enough to audit and merge safely.
- After each phase: run `create_codebase.bat` (and `deploy_loopia.bat` if Loopia is used).
