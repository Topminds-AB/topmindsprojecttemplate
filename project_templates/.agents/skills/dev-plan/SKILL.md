# dev-plan — wrapper

Follow `<OBSIDIAN_VAULT_PATH>/skills/topminds/dev-plan/SKILL.md`
from session start through closure: `plan_next` first, one claimed item

decisions for Mattias become decision requests. The canonical master owns
the full contract; without MCP use the CLI fallback it names.
